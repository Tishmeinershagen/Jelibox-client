## 🧭 What Jelibox-client Does

Jelibox-client gives you a visual workspace for preparing image datasets. Instead of editing files by hand or writing scripts, you work with images directly in the app. You load images, draw labels around the objects you care about, review the results, and save everything in a format that training tools can read.

The application is built for tasks such as object detection, instance segmentation, bounding-box annotation, and polygon annotation. These terms describe common ways to teach a computer what appears in an image. A bounding box is a rectangle around an object. A polygon is a shape that follows the outline of an object more closely. Jelibox-client supports both so you can choose the labeling style that fits your images.

The tool is useful for beginners who are creating their first dataset and for experienced users who want a faster desktop workflow. You do not need programming knowledge to start labeling. The main actions happen through the app interface: open images, draw shapes, assign labels, run auto-labeling, review results, and export.

## ✏️ Drawing Boxes and Polygons

Bounding boxes are the fastest way to mark an object. You draw a rectangle around the object and assign it a label, such as person, car, package, defect, or any category you need. Boxes work well when the object has a clear outer edge and you only need to know where it is.

Polygons are better when the object has an irregular shape or when you need a tighter outline. You place points around the edge of the object and connect them into a shape. This is common for instance segmentation work, where the goal is to separate each object from the background and from other objects.

Jelibox-client is designed to make both methods practical in a desktop app. You can move between images, add labels, adjust shapes, and keep your dataset consistent. Clear label names and consistent drawing habits make the final dataset easier to use.

## 🤖 Auto-Labeling with YOLO-World or Your Model

Auto-labeling helps you get started faster. Instead of drawing every box or polygon by hand, you can let a model suggest labels for the objects in your images. Jelibox-client supports YOLO-World and your own model, so you can use a ready model or bring a model that matches your project.

YOLO-World is useful for open-vocabulary labeling. In simple terms, it can help identify objects based on the label names you provide. You set up the labels you want, run auto-labeling, and then review the suggestions. Reviewing is an important part of the workflow because automatic results can be incomplete or slightly off. The app lets you correct shapes, change labels, and fill in anything the model missed.

Using your own model is helpful when you already have a model trained for your images. You can use it to pre-label a new batch and then refine the results. This can save time on large projects where many images share similar objects and scenes.

## 🗂️ Organizing Your Project

A clear project structure saves time. Keep your images in one folder and your labels in another, or use the project structure that Jelibox-client creates for you. Use short, descriptive label names. For example, use car instead of vehicle_type_1 unless you truly need that level of detail. Consistent names reduce confusion when you review your dataset.

If you work with multiple people, agree on label names before you start. Changing label names after many images are labeled can create extra work. A simple label list and a short description of what each label means can keep everyone aligned.

## 🔍 Reviewing and Correcting Labels

Reviewing is where you catch mistakes. Auto-labeling and manual drawing can both produce errors. Check that each object has the right label, that boxes are not too loose or too tight, and that polygons follow the object outline. Remove labels from objects that should not be included. Add missing labels where needed.

Work in short sessions and review a few images at a time. This helps you stay focused and catch patterns of mistakes. If you notice the same error repeatedly, correct your label setup or adjust your auto-labeling settings before continuing.

## 📚 Working with Large Image Sets

Large datasets can be handled in batches. Label a small group, review it, and then continue with the next group. This keeps the project manageable and lets you spot problems early. If you use auto-labeling, pre-label a batch and then review it before moving on.

Keep notes about your progress, such as which folders are complete and which still need review. Good notes make it easier to pause and resume work without losing track.

## 🧾 Understanding Label Formats

A label file tells a training tool what objects appear in an image and where they are located. Different formats store this information in different ways. YOLO format typically uses one text file per image. COCO format uses a single structured file for the dataset. Pascal VOC uses XML files.

Jelibox-client handles the export step so you do not need to create these files by hand. You focus on labeling in the app, choose an export format, and let the app produce the files.

## 💡 Tips for Better Labels

Use label names that are easy to understand and spell. Keep the number of labels small at first. Label the most important objects first, then expand if needed. Draw boxes that fit the visible object without including too much empty space. For polygons, use enough points to follow the outline but not so many that the shape becomes difficult to edit.

Check a few images after export to confirm the files look correct. If you plan to train a model, a cleaner dataset usually leads to better results.
